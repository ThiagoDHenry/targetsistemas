## Problemas Resolvidos

## Linguagem javascript

1. Cálculo da variável SOMA
Descrição: Dado o trecho de código:

int INDICE = 13, SOMA = 0, K = 0;
Enquanto K < INDICE faça { K = K + 1; SOMA = SOMA + K; }
Imprimir(SOMA);
O programa calcula o valor final da variável SOMA após o processamento.

Saída esperada:
Valor de SOMA: 91

2. Verificação de número na sequência de Fibonacci
Descrição: O programa verifica se um número fornecido pertence à sequência de Fibonacci. A sequência começa com 0 e 1, e cada número seguinte é a soma dos dois anteriores (exemplo: 0, 1, 1, 2, 3, 5, 8, 13, ...).

Entrada:
Um número definido no código (exemplo: 21).

Saída esperada:
O programa informa se o número pertence ou não à sequência.

3. Análise de faturamento diário
Descrição: Dado um vetor com os valores de faturamento diário de uma distribuidora, o programa calcula:

O menor valor de faturamento diário;
O maior valor de faturamento diário;
O número de dias com faturamento superior à média mensal (desconsiderando dias sem faturamento).
Entrada:
Um vetor contendo valores diários de faturamento.

Saída esperada:
Os valores mínimo, máximo e o número de dias acima da média.

4. Percentual de representação por estado
Descrição: Dado o faturamento mensal detalhado por estado, o programa calcula o percentual de representação de cada estado no total mensal.

Entrada:
Valores de faturamento de estados: SP, RJ, MG, ES e Outros.

Saída esperada:
O percentual de cada estado no faturamento total.

5. Inversão de caracteres de uma string
Descrição: O programa inverte os caracteres de uma string fornecida, sem utilizar funções prontas como reverse().

Entrada:
Uma string definida no código (exemplo: ParaVocê).

Saída esperada:
A string original e a string invertida.
